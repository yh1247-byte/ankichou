カードを取り込む

CSV / TSV を読み込みます。タグ列の :: 区切りが、そのまま画面の階層（デッキ）になります。複数ファイルを一度に選ぶと、1列目=表・2列目=裏・::を含む列=タグ として一括で取り込みます（列の手動指定は単一ファイル時のみ）。Anki の #separator: / #tags column: 行と {{c1::…}} クローズにも対応。

タップして選択
または ここにドロップ（複数可）
Ankiの書き出し：ノート→書き出し→「メモをテキスト形式で」。あなたの あはき師::科目::章::節 タグはそのまま階層になります。同じタグに追記した場合はカードが増えるだけで、既存の学習進捗は消えません。

オプション

Anki の「デッキオプション」に相当。変更はすぐ保存されます。学習の記録は操作のたびに自動でこの端末に保存されます。

日次制限

上限は全デッキ共通。復習は上限を掛けない（9999）のが原則：切ると未消化が溜まり間隔が崩れます。今日だけ増やす時は概要画面の「カスタム学習」。

新規カード

「もう一度」で最初のステップに戻り、最後のステップを「普通」で通過すると FSRS の間隔へ卒業。既定は 10分 のみ（直後の再テストは効果が薄く、1日を超えるステップは FSRS と干渉）。空欄で即卒業。

失念（Lapses）

「もう一度」を押した復習カードの失念回数がこの値に達すると ★ が付き、カードに「失念N回」と出ます。非表示にはしません（0で無効）。
この端末の保存領域はブラウザの都合で消えることがあります。一覧に「前回のバックアップから N日」と出ます（0で催促なし）。
一覧の末尾に「⊘ 非表示 · 次回 M/D」が出ます。期日が来たら1枚ずつ「戻す／そのまま／削除」で判断。評価はしないので間隔データは変わりません。

表示順序・時刻

FSRS

高くするほど復習が多く・間隔が短く、確実に。低くすると復習は減るが忘れやすい。90%が標準。試験直前は上げる使い方も。
試験日を入れると、①直前期は保持率を自動で引き上げ、②間隔を「試験前日まで」で上限にして全カードが試験前に必ず1回出るようにします。
評価は基本「もう一度／普通」の2択で。「難しい」「簡単」を多用すると FSRS の推定が歪みます。復習の上限は設けず（9999）、新規は 20/日を目安に。
「復習ログをCSVで書き出し」→ PC の fsrs-optimizer で最適化した値を貼り付け。空欄で既定値。

カードを編集

選択した語を {{c1::語}} で囲むと穴埋めカードに。番号ごとに1枚ずつ作られます。
つながりで覚える：行の頭に → を付けて段を順に書くと、「前の段を見て次の段を当てる」カードがつながりごとに1枚、3段以上なら「最初から通して言う」カードも1枚できます。1行目を「？」で終わらせるとそれが題になります。
改行はそのまま反映。*文字* で強調。クローズの場合は「補足」として答えの下に出ます。
末尾の S / A / B / C / D はレベルとして扱われます。

タグを編集

末尾だけ変えれば改名、親を変えれば移動、既存パスを入れれば統合。配下カードのタグを一括で書き換えます（id・学習履歴は保持されます）。
