# 暗記帳

間隔反復（FSRS）で覚える暗記アプリ。HTML 1ファイルで動きます。

公開URL: https://yh1247-byte.github.io/ankichou/

学習データはブラウザ（localStorage / IndexedDB）にだけ保存され、このリポジトリには送られません。端末ごとに別のデータになるので、端末間の移動はアプリのバックアップ書き出し・復元を使ってください。

## つながりで覚えるカード

表に、行の頭に `→` を付けて段を順に書くと「つながりカード」になります（→ の行が2行以上のとき）。1行目を「？」で終わらせると、それが題になります。

```
放射線の影響が出やすい部位はどう判断する？
→ DNAが傷ついた細胞は、分裂するときに細胞死する
→ 分裂しやすさで、細胞を部位ごとに分けられる
→ 分裂が盛んな部位ほど影響が出やすい
```

前の段を見て次の段を当てるカードが、つながりごとに1枚ずつできます。3段以上なら、最初の段だけを見て残りを順に言う「通し」のカードも1枚できます。
